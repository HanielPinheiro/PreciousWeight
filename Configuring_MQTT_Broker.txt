Step 1: Install OpenSSL
Step 2: Create the Certificate Authority
openssl genrsa -out ca.key 2048
openssl req -new -x509 -days 3650 -key ca.key -out ca.crt
**The most important part is “Common Name” = precious_weight. It should be a name that identifies the CA.
openssl genrsa -out server.key 2048
openssl req -new -key server.key -out server.csr
**Again, you’ll be asked for some information. For the common name, you should use the IP address or hostname of your MQTT server.
openssl x509 -req -in server.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out server.crt -days 3650
openssl genrsa -out client.key 2048
openssl req -new -key client.key -out client.csr
openssl x509 -req -in client.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out client.crt -days 3650

    *Edit the hosts file to map precious_weight to Windows Pc Local Ip (192.168.0.8):

       - Open the file C:/Windows/System32/drivers/etc/hosts.
       - Add the following line:
       - 127.0.0.1   precious_weight
       - Save the file.
   *Verify Hostname Resolution
    - In power shell ping precious_weight
    - You should see responses from Windows Pc Local Ip.

In the esp-idf:
 Generate the generate CA.crt and Generate Client Certificate (signed by your CA):
        openssl genrsa -out client.key 2048
        openssl req -new -key client.key -out client.csr
        openssl x509 -req -in client.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out client.crt -days 365
		Put the three files in the esp-idf folder:
			client.crt → client_cert_pem_start
			client.key → client_key_pem_start
			ca.crt → cacert_pem_start
